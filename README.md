# HYDROVEST LIFE JACKET
### Development of a Smart Life Jacket with GPS-GSM Emergency Alert, SOS Cancellation, and Visual-Audible Signaling System

## Project Overview

The HydroVest Life Jacket is a smart safety device developed to assist people during floods and other water-related emergencies. It integrates GPS and GSM technologies to provide location information and send emergency SMS alerts to designated recipients.

The system also includes an SOS activation and cancellation feature, LED visual signaling, and a buzzer for audible emergency alerts.

## Project Objectives

- Provide GPS-based location information during emergencies.
- Send emergency SMS alerts using GSM technology.
- Allow users to activate and cancel SOS alerts.
- Provide visual and audible emergency signaling.
- Support communication between people in distress and rescuers.

## Main Features

1. **GPS Location Tracking** – Uses the NEO-6M GPS module to obtain location coordinates.
2. **GSM Emergency Alert** – Uses the SIM800L module to send SMS notifications.
3. **SOS Button** – Allows the user to activate an emergency alert.
4. **SOS Cancellation** – Allows the user to cancel an active emergency alert.
5. **LED Signaling** – Provides visual emergency signals.
6. **Buzzer Alert** – Provides audible emergency signals.

## Hardware Components

| Component | Function |
|---|---|
| ESP32 DevKit V1 | Main microcontroller |
| NEO-6M GPS | Location information |
| SIM800L GSM | SMS communication |
| Buck Converter | Power regulation |
| 18650 Batteries | Power supply |
| LED Lights | Visual signaling |
| Buzzer | Audible signaling |
| SOS Button | Emergency activation |

## Testing and Demonstration

The prototype underwent testing and demonstration activities, including a beach water test, to observe its performance in a water-related environment.

## Project Limitations

The prototype depends on GPS signal availability, GSM network coverage, and sufficient battery power. Its emergency communication capabilities may be affected by environmental and network conditions.
